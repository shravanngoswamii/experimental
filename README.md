# Experimental Workspace

This repository is a personal sandbox for prototypes, backup apps, and paper drafts.

## Major Areas

- `DoodlePPL/`: Experimental and backup variants of DoodleBUGS apps.
- `GSoC-Backup/`: Archived implementation snapshots.
- `JOSS-reviews/`: Review and paper-related resources.
- `Research-Work/`: Drafts for ongoing research writing.
- `sample/`: Astro sample project.
- `navbar/`: Scripts for injecting a shared navbar into static HTML files.
- `tools/`: PowerShell helpers to discover Node projects and HTML targets.

## Root Landing Page

- `index.html` is a lightweight static overview of the repository structure.
- It is intentionally dependency-free so it can be viewed directly without a build step.

## Handy Commands

- `./tools/list-node-projects.ps1` lists detected Node project roots.
- `./tools/list-html-targets.ps1` lists HTML files while skipping common build folders.
