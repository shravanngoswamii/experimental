# Experimental Workspace

Personal sandbox for prototypes, archived experiments, and writing drafts.

## Main Folders

- `DoodlePPL/`: Experimental and backup variants of DoodleBUGS apps.
- `GSoC-Backup/`: Archived implementation snapshots.
- `sample/`: Astro sample project.
- `tools/`: Small PowerShell helper scripts.

## Useful Tools

- `tools/list-workspace-items.ps1` (single script for node, vite, julia, html, astro-pages, markdown, and manifests listings)

For primary public-facing work, visit [shravangoswami.com](https://shravangoswami.com).
