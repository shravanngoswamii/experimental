Repository overview

Experimental monorepo with prototypes, papers, and utilities

The root workspace combines frontend prototypes, Julia runtimes, paper-writing artifacts, and helper scripts. It acts as a staging ground for multi-canvas UI ideas, archived GSoC experiments, and publication support assets.

Primary stack

Vue + Vite, Julia runtime services, and script-driven tooling.

Main focus

DoodleBUGS variants, multi-canvas workflows, and model-driven experiments.

Repo shape

Multiple active project roots with shared docs, tests, and utilities.

Directory map

Key folders and what they contain

Path Purpose Notable contents
DoodlePPL/ Main experimentation area for DoodleBUGS and multi-canvas implementations. Figma-like-DoodleBUGS-MultiCanvas, GSoC-DoodleBUGS, PrimeVue variant, runtime server.jl, and model JSON files.
GSoC-Backup/ Archived and comparative snapshots from earlier project iterations. Code, DoodleBUGS, and TEST branches with Vite-based app setups.
sample/ Separate Astro playground for lightweight UI/content experiments. Astro config, page/layout components, styles, and public assets.
JOSS-reviews/ and mlg-format/ Publication and formatting resources for paper submissions and reviews. paper.md, bibliography files, and md-to-pdf helper commands.
tools/ and navbar/ Automation scripts for discovery, listing, and HTML navbar insertion tasks. PowerShell project listing scripts and Julia/Shell navbar helpers.
Research-Work/ and OpenSource/ Draft research writing and open-source setup notes. Paper drafts for deepfake, hibiscus, log analysis, and setup docs.

Workflow notes

Practical contributor guidance

  • Use the DoodlePPL subprojects when testing active UI/runtime ideas.
  • Use GSoC-Backup only for historical comparison or rollback reference.
  • Use tools scripts to quickly locate Node projects or HTML targets before batch edits.
  • Keep documentation and research edits separate from app code commits when possible.
